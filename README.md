# Spicetify-Updater: A non-intrusive one
A **non-intrusive** Spicetify Updater with Version Control because others couldn't do it.

## What makes this different than other Spicetify Updaters?
This Spicetify Updater is **non-intrusive**. What do I mean by non-intrusive? It's comfortable to use, and you wouldn't have to worry about having to update the updater when the updater receives an update.

This Spicetify Updater is also cleaner, **compact** and is purely automatic. Run the Batch file and it will automatically put it in Startup.

## Installment
1. Download the latest release in https://github.com/nelvismyname/Spicetify-Updater/release
2. Run the `Spicetify Updater.bat`

And that's pretty much it, you can forget about it.
